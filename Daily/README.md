# 使い方の例 (Usage Examples)

このフォルダには日々の記録が保存されます。

## 例: 日記エントリーの追加

```bash
# 簡単な記録
./quick-daily.sh "今日は良い一日だった"

# 複数回追加可能（同じ日に複数エントリー）
./quick-daily.sh "朝：運動した"
./quick-daily.sh "夜：本を読んだ"
```

これにより以下のようなファイルが作成されます：

```markdown
# Daily Log - 2026-01-20

## 09:00:00
朝：運動した

## 21:00:00
夜：本を読んだ
```

毎日のエントリーは同じファイルに時刻付きで追加されます。
