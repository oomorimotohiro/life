# 使い方の例 (Usage Examples)

このフォルダには目標が保存されます。

## 例: 目標ファイルの作成

```bash
./quick-goal.sh "プログラミングを学ぶ" "Pythonから始める"
```

これにより以下のような目標ファイルが作成されます：

```markdown
# プログラミングを学ぶ

**Created:** 2026-01-20
**Status:** 🎯 Active

## Description
Pythonから始める

## Progress
- [ ] Started

## Notes

```

進捗を更新するには、ファイルを直接編集してください。
